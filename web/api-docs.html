Targeted Virtual Number Purchase

POST /api/v1/purchase Alias: /api/purchase X-API-Key + X-NexNum-Key

Acquires a NexNum number, runs a silent platform check, queues mismatches for refund, and returns the NexNum order_id upon matching target_status.

Rules & Notes

        

          Rules: BAD_KEY (400) & NO_BALANCE/BANNED (402) stop immediately. Two consecutive inconclusive checks (ERROR/TIMEOUT/UNKNOWN/DISABLED) abort with 422 CHECKER_INCONCLUSIVE. Keep max_attempts within Nginx 60s timeout.
        

        

          Test Bypass: ENVIRONMENT=testing or X-Test-Bypass: 1 injects tg_99999999. Never enable in production.
